# UI Spec — Light Minimal

## Visual tone
- clean white/light surface
- restrained indigo/cyan accent
- premium typography
- large spacing
- rounded 18–28 dp cards
- no glassmorphism
- no toolbox grid

## Home hierarchy
1. Header: Fitsize + Settings
2. Hero: Compress Video
3. Select Video CTA
4. Short explanation of compression flow
5. AdMob banner/adaptive banner
6. History
7. You saved X GB

## Compression screen
- source thumbnail/metadata
- original size prominently
- three quality profiles: Balanced / Smaller / Smallest
- each profile shows estimated output with `≈`
- one primary Compress Video button
- no ad while processing

## Result / success screen
- positive success headline, not only `Done`
- `1.0 GB → 780 MB` style before/after
- `You saved 244 MB` style measured saving
- percent saved
- selected profile
- elapsed time
- primary action: Share Video
- secondary: Open in Gallery
- tertiary: Compress Another
- dedicated 300×250 MREC below the result/actions with safe spacing

The ad must never visually imitate a result button or be placed so close to Share/Open controls that accidental taps become likely.

## App Open
App Open is part of monetization but not part of the visual Home layout. It is shown only at appropriate app-entry/loading moments after warm-up and cooldown rules are satisfied.
